# **App Name**: La Vie est Belle - Soin Esthétique Nussbaumer

## Core Features:

- Homepage Hero Section: Display a large, high-definition image with a title and CTA button.
- Services Grid: Display services in a grid of cards with clickable categories for details.
- Dynamic Services Menu: Fetch service details (name, duration, price) from Firestore.
- Admin Interface: Provide a protected route/interface for modifying service prices and descriptions without code changes.
- Contact Form Submission: Save contact form messages to a Firestore collection.
- Google Maps Integration: Integrate Google Maps with clear opening hours and contact information.
- Testimonials Section: Elegantly display customer reviews.

## Style Guidelines:

- Background color: Soft off-white (#FDF2F2) for a clean, minimalist feel.
- Primary color: Muted beige (#D4A373) to evoke a sense of luxury and nature.
- Accent color: Light peach (#EAC696) to add warmth.
- Font recommendation: 'PT Sans', a sans-serif for a professional, clean aesthetic suitable for both headlines and body.
- Minimalist design with ample white space.
- Mobile-first approach with a hamburger menu on smartphones and visible 'Click-to-Call' buttons.
- Simple, elegant icons for service categories.
